# YoFinanzas

Aplicación de consola en Python en proceso de desarrollo, orientada a organizar información sobre ingresos y gastos personales.

## Objetivo

Construir progresivamente una aplicación que permita registrar y consultar movimientos financieros personales, con una estructura modular y una interfaz sencilla por consola.

## Tecnologías y conceptos

- Python
- Funciones y módulos
- Organización del código en archivos separados
- Estructuras de datos
- Menús interactivos por consola

## Estructura actual

El código se organiza dentro del directorio `src/`, donde se encuentran módulos relacionados con la lógica principal y el menú de la aplicación.

La implementación actual incluye estructuras para clasificar ingresos y gastos, junto con funciones destinadas a consultar estas categorías.

## Instalación y ejecución

Cloná el repositorio:

```bash
git clone https://github.com/Th-30Mateo/YoFinanzas.git
cd YoFinanzas
```

Revisá los archivos dentro de `src/` antes de ejecutar la aplicación. El proyecto todavía requiere integración y pruebas para confirmar que el menú y las funciones estén conectados correctamente.

## Estado del proyecto

**En desarrollo.** La aplicación todavía no debe considerarse una solución completa de gestión financiera.

Entre los aspectos pendientes se encuentran:

- Integrar correctamente las opciones del menú con las funciones correspondientes.
- Completar y validar los flujos de consulta y gestión de movimientos.
- Manejar entradas incorrectas y casos sin datos.
- Definir cómo se almacenarán los movimientos y si se conservarán entre ejecuciones.
- Incorporar pruebas para verificar el comportamiento de las funcionalidades.

## Limitaciones actuales

- No se ha verificado que todos los flujos de la aplicación funcionen de extremo a extremo.
- No se ha confirmado almacenamiento persistente de las transacciones.
- No debe utilizarse como sistema financiero de confianza.

## Objetivo de aprendizaje

Desarrollar habilidades de programación con Python, separación de responsabilidades, integración entre módulos y depuración progresiva de una aplicación.
